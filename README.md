# Pelita Cafe Revamp (`pelita-cafe-revamp`)

A modern, production-ready website overhaul for **Pelita Cafe** (`pelitacafe.com`), blending authentic heritage coffee roasting and Malaysian comfort cuisine with the editorial elegance, clean palette, and homepage gallery carousel layout of **Sama Sama Cuisine** (`samasamacuisine.com`).

---

## 🌟 Tech Stack & Highlights

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, Turbopack ready)
- **Language**: TypeScript (Strict Mode)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom brand theme tokens:
  - *Cream Canvas*: `#FFF9EE`
  - *Espresso Brown*: `#603814`
  - *Caramel Gold*: `#D8B978`
  - *Terracotta Burgundy*: `#7E2A2A`
  - *Dark Roast*: `#170F0A`
- **Icons**: [Lucide React](https://lucide.dev/)
- **Forms & Validation**: [React Hook Form](https://react-hook-form.com/) + [Zod](https://zod.dev/) client-side validation
- **Typography**: Google Fonts via `next/font` (`Plus Jakarta Sans` & `Playfair Display`)
- **SEO & Social**: Semantic HTML5, dynamic OpenGraph, Twitter cards, dual-branch `Restaurant`/`CafeOrCoffeeShop` Schema.org JSON-LD

---

## 🚀 Key Features

1. **Brand Synergy & Design Architecture**:
   - Editorial clean canvas with soft cards, subtle borders, and smooth hover micro-interactions.
2. **Hero Showcase**:
   - Value proposition, social proof rating, direct WhatsApp order, and menu book modal CTA.
3. **Homepage Gallery Slideshow (Sama Sama Cuisine Style)**:
   - Autoplay, pause on hover, next/prev navigation, touch swipe support, and lightbox enlargement.
4. **Signature Menu Showcase & Book Viewer**:
   - Filterable categories: Signature Meals, Premium Coffee, Wok Specialties, All Day, Light Bites.
   - Interactive 9-page full menu book modal with keyboard navigation and thumbnail selector.
5. **Dual Branch Locations**:
   - Full address, operational hours, rest days, and direct Google Maps navigation for **Sepang Flagship** and **Putrajaya Branch**.
6. **Lead Capture & Table Reservation**:
   - Client-side validated form (Name, Email, Phone, Branch, Reservation Type, Pax, Date, Time, Special Notes).
   - Instant WhatsApp forwarding concierge button upon submission.
7. **Customer Testimonials**:
   - "Real Feedback, Real Flavour" editorial quotes with 5-star ratings.

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
